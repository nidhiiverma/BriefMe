# BriefMe - Lecture Notes to Study Pack

AI-powered study pack generator built with Prompt Chaining, Strict JSON Schema Outputs, and Automated Rubric Evaluation using Groq (openai/gpt-oss-120b & openai/gpt-oss-20b).

## How to Run Locally
1. pip install -r requirements.txt
2. streamlit run code/app.py
